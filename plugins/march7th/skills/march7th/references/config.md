# 配置含义与生效

三月七的宿主设置、组合任务的启用内容、某次运行的目标以及 Pudding 保存的快捷入口不是同一层。用户只改一项时先确认其作用对象，不能为调整一个任务的表现去改无关的宿主默认、其他入口或游戏现场。

启用开关决定组合执行是否包含某项内容，不一定阻止直接运行对应的独立任务。执行目标、队伍选择、资源消耗与结束后的处理也各有含义，不能只看一个开关就解释整项任务。具体定义和适用条件从当前设置说明取得，未知单位或取值不凭名字猜测。

当前桥只开放宿主现存设置中的有限部分；能读到某项设置，不代表能够写它。只改用户点名且声明允许的内容，保留其余字段与外部修改。通知、账号等遮蔽值不是可用的新值，不能把占位内容保存回去。

保存成功、宿主内存已更新、下次任务读取到新值和游戏中已经产生效果分别确认。任务运行中变更设置是否立即影响当前任务，须看本次契约或对应源码，不能默认即时生效，也不为验证设置而擅自运行游戏。

实际读写、冲突和核验方式见 march7th-operator 的设置资料；需要分析效果时读取其诊断资料，不把普通参数解释扩展为收益承诺。
