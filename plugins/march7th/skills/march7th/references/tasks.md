# 任务与宿主对象

内置任务是宿主已经实现的业务入口，组合执行则按宿主保存的启用项组织一组行为。运行一个独立任务与运行整套保存配置的影响不同，不能因两者涉及相同游戏内容就相互替代；具体范围应从当前目录说明和实际配置确认。

当前插件面向一个已连接的三月七宿主及其执行进程，不提供 BGI 式的独立配置组管理。Pudding 中保存多个入口，不会因此在三月七里产生多份互不影响的配置；它们可能仍读取同一套宿主设置。不能靠反复切换全局设置、启动后再改回来，伪装成可并发的独立任务。

任务是否出现在宿主清单、是否允许经桥调用、当前能否开始，是不同问题。目录中的实际对象和允许范围要在本次连接核实；软件源码里的菜单或实现不能直接当成已开放接口。反复执行、升级维护等行为也不能由普通单次启动请求推导出来。

游戏账号与服务器属于游戏现场，助手界面、Pudding 会话和桥连接不等于账号身份。没有账号范围证据时，不能说已为某个账号运行；连接成功也不证明账号已登录。只在当前能力明确支持并说明切换语义时处理账号切换。

需要具体操作时读取 march7th-operator：按目标选择任务对象、执行或结果资料。不要从本页推测具体任务标识，也不把之前运行过的对象当成本次仍可用。
