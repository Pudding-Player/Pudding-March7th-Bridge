# 快捷入口与顺序

只封装用户指定的已有内置任务及其现有配置，不把一次运行改造成新业务实现。保存前从当前能力确认目标和允许范围，复用发布绑定所支持的稳定对象与只读准备，不能把旧连接的临时标识、修订依据或进程状态直接保存成以后执行的参数。

快捷入口属于 Pudding 的编排，宿主配置仍由三月七管理。同一宿主下多个入口可能共享设置；用户要不同配置时，先核对当前能力是否能表达这种独立性，不通过“改全局设置再还原”拼出一个看似独立的入口。

用户要求多个动作时保留顺序、重复项与间隔。前项完成后再运行下一项，需要真实的业务完成证据；只确认开始不能满足这个条件。当前绑定若不能表达完成等待或运行时准备，应指出缺少的能力，不能用固定等待时间或保存日志最后一行来替代。

保存、发布、运行分别处理。只要求封装时不试跑、不启动游戏；修改已有入口保留身份和其他项。后续执行发现任务已移除、连接变化或契约不兼容，应按当前对象重新核对，不能擅自换成名称近似的任务。
