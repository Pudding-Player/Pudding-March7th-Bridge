# 连接与现场判断

Pudding 与桥的通信、桥找到三月七现有界面对象、三月七能够操作游戏，是三层不同的条件。前一层正常不能证明后一层已就绪；后一层未就绪也不能反推所有配置查询都不可用。

连接失败只证明本次访问没有完成，不能断言三月七进程不存在、游戏关闭、任务不支持或配置丢失。应先根据实际错误区分地址不可达、鉴权、宿主对象未找到、版本不匹配和界面线程暂时忙碌；只有回执指向的问题才能作为结论。

桥依附于用户已有的三月七界面，不是把三月七“附着到游戏”。助手不自行运行注入器、安装器、更新器或另一个解释器，也不猜其他端口、读取凭据或通过文件修改绕过连接要求。人工连接说明供确需处理连接问题时使用，不作为每次启动前都要用户完成的检查表。

宿主忙碌、请求尚未开始、执行中超时和结果未知必须按当前回执分别处理。没有明确的未提交证据，就不能把超时当成安全重试；重连后要重新取得对象与版本，旧连接中的标识不是长期凭据。

明确连接不可用时说明当前阻碍并结束；用户提供恢复的新信息后再查询。状态读取正常但业务被拒绝时，按业务原因处理，不建议无依据的重启、重新连接或手动运行。
