# 三月七小助手使用约定

先理解目标和必要条件，再选择能力。游戏对象与需求之间的对应关系须有用户给定或可靠资料支持，缺依据时补齐领域事实；宿主任务目录用于核对本机可执行对象，不能代替游戏知识。已有依据足够时直接复用，不例行联网，也不从近似任务名猜业务含义。

- 查询任务、修改设置、执行与排障：读取 march7th-operator，按需选择一份操作资料。
- 理解内置任务、组合执行和已有配置的关系：读[任务与宿主对象](references/tasks.md)。
- 判断设置的作用层与继承影响：读[配置含义与生效](references/config.md)。
- 区分助手连接、宿主界面与游戏就绪：读[连接与现场判断](references/connection.md)。
- 封装用户已有任务：读[快捷入口与顺序](references/quick-tasks.md)。

技能不列具体玩法、接口、类名、参数路径或页面标识。当前工具契约和宿主目录决定实际对象、参数与前提；源码里存在一项功能不证明桥已开放。已有说明足够时直接处理，需要判断依据时才加载相关资料，不顺次读完整套手册。

优先使用应用的数据和完整任务能力，沿用已保存的有效设置。只问会改变结果且无法自行观测的用户取舍，不因配置包含队伍或资源选项就例行重问。查询和配置不自动扩大为运行，普通启动得到确认后结束，不把“启动”扩写成持续监控。
