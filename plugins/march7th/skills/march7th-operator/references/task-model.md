# 任务对象

先把用户的游戏目标与宿主任务的实际职责对应起来。任务名称只用于定位候选，执行范围、资源消耗和结束条件要由当前说明或对应版本源码确认；同一游戏目标可能只占组合执行的一部分，不能用范围更大的组合任务替代。

内置任务是稳定的业务入口，组合运行会读取宿主保存的启用内容。选择哪一个入口与打开哪些组合开关不是同一动作；用户说“运行现有任务”不自动授权修改所有启用项，用户说“先配好”也不授权启动。

三月七的当前界面和执行进程构成本次宿主范围。不要从 Pudding 的多个会话、多个快捷入口或上次任务名称推断有多个可并行的宿主实例。已有任务仍在启动或运行时不能叠加新任务，也不能未获要求就停止它。

暂停、停止、任务结束后的等待确认和关闭宿主界面是不同操作。某个设置控制结束后的等待，不证明桥提供了运行中暂停。当前契约没有暂停或恢复入口时，说明桥的覆盖范围，不能把停止悄悄当作暂停。

目录标识来自本次实际结果。重连或版本改变后重新确认，不复用历史会话标识，不把目录标签、内部任务标识和配置字段互相替代。
