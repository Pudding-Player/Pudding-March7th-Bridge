# 设置修改

按用户可见用途读取当前配置和可写说明，核对字段所属、当前值、类型、选项、单位、适用任务和版本。能读到的配置范围大于允许写入的范围，不能从读取成功推断任何设置都可保存。

可写说明只覆盖本桥开放的部分设置，不保证可读配置中的每一项都有完整业务定义。解释未公开的字段时，需要对应版本的说明或已授权源码；读到了一个值，不代表已经查明它的单位、条件和使用位置。

任务启用项、执行目标、队伍或资源选项、对话处理和任务结束后的动作应按各自定义解释。一个选项对组合执行有效，不代表它会改变独立入口；结束后暂停确认也不代表运行中暂停。说明没有给出单位或生效条件时，先查定义，不从键名猜测。

只修改本次要求且当前宿主确实存在、允许写入的字段。保留未涉及内容，不把脱敏视图重建成整份配置，也不将被遮蔽的值或未知字段写回。路径、外部程序、命令、维护与计划等限制不能用相近字段绕过。

使用当前配置修订依据和会话依据提交。明确的版本冲突说明本次未按旧条件修改，应重新读取并保留并发变化后再决定；不是把旧值原样再发一次。未知结果先只读回查，不能当作未执行。

成功后的核验覆盖宿主保存方法及回读到的值，不是任意外部编辑器之间的原子事务。区分已保存、下次运行生效和游戏中实际效果，不为说明设置自动启动任务或承诺收益。
