# 三月七小助手操作

先确定用户指的是宿主设置、内置任务、组合执行、当前运行还是日志结果。它们的对象和核验方式不同，不把一个查询失败扩写成整个软件没有该功能。

从当前工具的用途、前置条件和影响选择能力，读取真实契约与现场对象后再填写参数。已经足够完成一次查询或修改时直接处理；需要判断对象、影响或证据时只读相关资料，不机械地逐项加载。

| 内置任务、组合执行与宿主范围 | [任务对象](references/task-model.md) |
| 设置含义、有限写入与生效 | [设置修改](references/settings.md) |

修改、保存、准备和运行按用户范围分别执行。优先复用宿主已有行为，不另写脚本、改安装文件或借原生界面绕过桥的限制。自己的对象和参数错误按当前契约修正，未知结果先核实，不重复可能已经执行的动作。
